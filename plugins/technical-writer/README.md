# technical-writer

Technical documentation writing, review, and sentence polishing for developer docs.

## Skills

| Skill | Purpose |
| --- | --- |
| `/technical-writer:write` | Write a new document (delegated to the technical-writer agent) |
| `/technical-writer:review` | Review an existing document and report issues with fixes |
| `/technical-writer:polish` | Polish sentences inline, without delegation |
